## 2. Калькулятор калорий

[calorie-calculator/](calorie-calculator/) — веб-приложение для подсчёта калорий за день.

**Как запустить:** открыть файл `calorie-calculator/index.html` в браузере (двойной клик).

**Что умеет:**
- добавлять продукт: название, калорийность на 100 г и вес порции — калории считаются автоматически;
- удалять продукт или очищать весь список;
- показывать общий итог за день;
- **сохранять данные** — продукты, итог и цель хранятся в `localStorage` браузера и не пропадают после обновления страницы или перезапуска браузера;
- ⭐ **дневная цель по калориям** — полоса прогресса показывает, сколько осталось до цели, и становится красной, если цель превышена.

**Файлы:**
- `index.html` — разметка страницы;
- `style.css` — оформление (есть светлая и тёмная тема, работает на телефоне);
- `app.js` — логика: добавление, удаление, подсчёт, сохранение.
